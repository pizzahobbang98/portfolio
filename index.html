대표 프로젝트

문제를 발견하고 분석한 뒤,
실제 서비스로 구현한
대표 프로젝트를 정리했습니다.

Problem

임산부는 몸과 감정 상태가 자주 변하지만, 매번 앱에 상태를 기록하거나 여러 가전을 직접 조작하기 어렵습니다. 배우자 역시 언제 도움이 필요한지 바로 알기 어렵습니다.

Approach

임신 관련 데이터를 수집·정제한 뒤, 비슷한 고민을 가진 고객을 분류하고 주요 관심사를 분석했습니다. 이후 중요도와 만족도를 비교해 우선 해결할 문제를 선정했습니다.

Role

서비스 기획과 고객 데이터 수집·분석을 담당하고, 분석 결과를 바탕으로 프론트엔드, AI·외부 API 연동, 데이터 저장 구조와 시연 환경까지 구현했습니다.

정리
469,020건의 고객 데이터에서 문제와 기회영역을 도출하고,
그 결과를 음성 입력 → AI 판단 → 가전·조명 제어 →
3D 공간 반응 → 실행 로그 저장으로 이어지는
시연 가능한 MVP로 구현했습니다.

Problem

HR 담당자는 여러 지원자의 진행 상태와 미처리 업무를 동시에 확인하고, 면접관들의 일정을 하나씩 비교해 면접 시간을 조율해야 합니다. 관리할 지원자가 많아질수록 중요한 업무를 놓치기 쉽습니다.

Approach

Spring Boot와 PostgreSQL이 채용 상태를 관리하고, Hermes가 사용자의 요청에 맞는 기능을 선택하며, Agentria가 업무 우선순위 분석과 면접 가능 시간 계산을 담당하도록 구성했습니다.

Role

채용 도메인과 데이터 구조 설계부터 Backend API, HR Dashboard, Hermes·Agentria 연동, Google Calendar 일정 조회, 지원자 안내 메일 초안 생성까지 전체 흐름을 직접 구현했습니다.
